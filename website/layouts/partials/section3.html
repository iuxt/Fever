第一次使用 Fever

01   安装应用与 Git

下载并安装对应系统的 Fever。桌面版需要系统安装 Git 和 Git LFS，并能从 PATH 找到它们。macOS 安装包目前未签名或公证，Windows 安装包也尚未签名。

02   选择一个本地笔记库

首次启动时选择一个空文件夹，或已有的 Fever 笔记库根目录。应用会初始化独立的 Git 仓库；在设置中填写 Git 用户名和邮箱，就可以开始写作与提交。

03   按需连接自己的远程仓库

如需通过 Git 同步，在设置中填入自己的远程仓库 HTTPS 或 SSH 地址。认证沿用系统 Git 的凭据或 SSH 密钥。离线写作无需远程仓库；本地定时备份也不会自动推送。

已有 Markdown 或 Obsidian 笔记？

Markdown 文件可直接导入；导入时相对路径的图片不会自动复制。Obsidian 笔记库可使用仓库提供的迁移脚本，保留 Git 历史、图片与绘图。操作步骤见 迁移指南。
